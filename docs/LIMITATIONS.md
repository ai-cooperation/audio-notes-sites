# 限制、成本與驗收狀態

## 音檔與 Groq

本程式 prepared 政策：單聲道16kHz／16-bit PCM WAV、每段目標120秒、重疊1秒、單片8MiB、單工作500MiB、最多1,000片。壓縮格式、VBR與副檔名都不適合直接推算會議時長；以FFmpeg解碼、實際bytes與時長為準。固定PCM每秒約32,000 bytes，因此500MiB單工作約容納4.5小時原音（含重疊及檔頭後略少）；更長會議需在Work建立多個工作，現有工具不會自動跨工作分批。每日8小時是轉錄額度，不是單工作容量。

Groq 官方於2026-09-15列免費方案單檔25MB；支援多種音訊格式，但本程式prepared入口只驗收WAV。服務 prompt 上限為224 tokens，本程式只按200字元截斷，字元不等於token，尚未實作224-token精確驗證；提示必須精簡。[Groq語音文件](https://console.groq.com/docs/speech-to-text)

官方 Whisper 免費表列每分鐘20請求、每日2,000請求、每小時7,200音訊秒、每日28,800音訊秒；額度以組織為單位，實際帳戶可能不同。[Groq額度文件](https://console.groq.com/docs/rate-limits)

程式已對prepared計算分鐘請求、小時／日音訊秒數；每日請求總數未另設本機硬上限，由429處理。重疊、重試與短片最少10秒均計入。其他應用及舊短檔路徑的消耗不在此帳本，不能宣稱精確掌握全部供應方餘額。

超限保存 waiting_quota／nextAttemptAt；優先依 Retry-After，未知時保守退避。不是台灣午夜保證重置。D1保存隊列不會自己喚醒 Work；本產品限定 Sites，未啟用外部常駐runner，關閉對話後不保證隔天自動續作。

## 功能邊界

|---|---|
| D1/R2、prepared驗收與佇列 | 已有程式與隔離測試；既有私人版處理過實際音檔 |

## 發布語句

可說「開源候選、私人會議工作台、Work搭配Sites與Groq、保存版本與詞庫」。不可說「無限免費」「特定訂閱必含Work」「全自動跨日」「即用OAuth MCP」「安全認證」「辨識率提升已量化」「SmallGreen Ready」。

詞庫、API測試及部署成功不等於逐句音訊準確率測試；有待確認詞就明確標記，不把原始辨識推測升格為永久事實。
